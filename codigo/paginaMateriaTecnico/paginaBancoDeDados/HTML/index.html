ATIVIDADE MODELAGEM CONCEITUAL

A modelagem conceitual é a primeira e mais crucial etapa na criação de um banco de dados. Ela foca em entender e mapear as informações de um negócio, usando ferramentas como o modelo Entidade-Relacionamento para definir o que é importante (entidades), suas características (atributos) e como se conectam (relacionamentos). É o projeto inicial que garante que o banco de dados final atenda às necessidades reais do negócio antes de passar para as fases técnicas de modelagem lógica e física.
